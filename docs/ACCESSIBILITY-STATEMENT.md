# Accessibility Statement - Fokus LocalStoragl

Fokus busca cumplir buenas prácticas de accesibilidad con base en WCAG 2.2 AA para ofrecer una experiencia inclusiva.

## Medidas implementadas

- HTML5 semántico: regiones estructuradas y roles claros.
- Etiquetado ARIA en componentes dinámicos.
- Estados ARIA para controles interactivos (`aria-pressed`, `aria-expanded`).
- Indicadores de foco visibles para navegación por teclado.
- Región de estado accesible para notificaciones globales.
- Etiquetas y descripciones en formularios.

## Estado actual

- Cobertura funcional de accesibilidad: implementada.
- Validación automática: recomendada con Lighthouse y axe.
- Validación manual: requerida en flujos críticos de teclado.

## Mejoras futuras recomendadas

- Atajos de teclado documentados en ayuda contextual.
- Pruebas periódicas con lector de pantalla (NVDA/VoiceOver).
